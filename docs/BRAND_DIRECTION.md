# BELLFLY — prelaunch identity, 2026-09-10

Working name: BELLFLY. Ticker undecided. This is a local visual/product direction, not a published or legally cleared brand. The user subsequently selected our existing [OCAT website](https://ocatcoin.xyz/) as the visual reference; it was inspected live in the browser and compared with the local `ocat/web/experience.css` implementation on this date.

## Direction

A fruit fly with an oversized ambition: ring the opening bell for its own memecoin. Lead with the fly, the joke and the intended consequence; let readers inspect the actual model below. The implemented OCAT-inspired direction uses electric green `#ccff00`, near-black `#101012`, milk `#f1efe8`, an oversized BELLFLY wordmark, heavy display typography, outlined buttons with hard shadows, side tapes, a slightly rotated character frame and black/cream section transitions. The inline SVG fly mascot remains original decorative interface artwork, explicitly separate from recorded neural measurements.

OCAT uses Archivo; this version uses heavy system display fallbacks rather than adding external font loading. No OCAT imagery, token address, trade action, live status, economic terms or account link is reused. No changes were made to the OCAT project or deployment. On mobile the character frame comes before the narrative, matching the reference's priority on the mascot.

Considered directions: an institutional neuroscience lab (clear but underplays the meme), generic trading-terminal chaos (recognizable but suggests market functionality we do not have), and a fruit-fly poster with inspectable proof. The third is implemented.
