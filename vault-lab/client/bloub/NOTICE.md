# Bloub animation engine

Unmodified framework-free source files from https://github.com/jeremy-prt/bloub, commit `b4bb3c1b5f93c7b87a2e8d620f667c4093d97749`, retrieved 2026-09-15. Copyright 2026 Jérémy Perret, MIT; see LICENSE and the distributed `/vendor/bloub-LICENSE.txt`.

Only the animation engine is included. Vault's DOM renderer, state mapping, vault door and layout are separate. No Vue runtime or remote iframe is loaded. The upstream project describes a recreation of an x.ai avatar; its code license does not establish ownership of the referenced design. Vault claims no affiliation with Bloub, its author or x.ai.
